# 단어 유형 라벨링 안내 (루마 JLPT 단어장)

이 문서만 보고 작업할 수 있게 썼습니다. 한 덩어리(청크)는 약 250단어이고, 단어마다 네 칸 `k`, `sk`, `ff`, `rt`를 채웁니다.

## 0. 왜 하는가

앱 사용자는 한국어 화자입니다. 일본어 단어 가운데 한국어 한자어와 뜻이 같은 단어(産業 = 산업)는 뜻을 이미 압니다. 앱은 이런 단어에서 **뜻 대신 읽기(さんぎょう)를 묻습니다.** 반대로 한자는 같은데 뜻이 다른 단어(工夫 ≠ 공부)는 **경고를 붙이고 뜻부터 확실히 가르칩니다.** 여러분의 판정이 바로 이 두 동작을 정합니다.

- `k = S`로 잘못 붙이면 사용자는 그 단어의 뜻을 한 번도 확인받지 않습니다. **애매하면 S를 주지 마세요.**
- `k = F`를 놓치면 사용자는 틀린 뜻을 확신한 채로 넘어갑니다.

## 1. 받는 파일

`n<급수>-<번호>.tsv` (예: `n5-2.tsv`). 스프레드시트(구글 시트, 엑셀)에서 열면 됩니다. 첫 줄이 열 이름입니다.

| 열 | 내용 | 수정 |
| --- | --- | --- |
| `id` | 단어 ID(`w0k3`, 안정 ID — docs/plan/08 §7). **절대 바꾸지 마세요.** | ✗ |
| `expr`, `reading` | 일본어 표기, 읽기(가나 단어는 비어 있음) | ✗ |
| `ko`, `en` | 앱의 한국어 뜻, 영어 뜻 | ✗ |
| `auto` | 기계 판정: `L`(가타카나뿐) / `K`(가나뿐). 한자가 있으면 비어 있음 | ✗ |
| `hint` | 기계가 짐작한 유형. **참고만 하세요.** 자주 틀립니다. | ✗ |
| `sk_candidates` | 한국 한자음 후보(공백 구분, 앞쪽이 유력) | ✗ |
| `rt_candidate` | 읽기 유형 후보 | ✗ |
| **`k`** | 단어 유형 — 아래 2절 | **채움** |

`k`(L/K일 때), `sk`(후보 1순위), `rt`(후보)는 미리 채워져 있을 수 있습니다. **미리 채워진 값도 반드시 확인하세요.**

## 2. `k` — 단어 유형 (모든 단어에 필수)

판정 순서가 중요합니다. **먼저 ①을 묻고, 아니면 ②로 갑니다.**

① **한국어에 같은 한자 단어가 있고, 한국 성인이 그 한자를 보면 그 단어를 떠올리는가?**
- 있고, 핵심 뜻이 같다 → **S**
- 있는데, 뜻이나 쓰임이 달라서 한국인이 틀리게 짐작한다 → **F**

② 없다면(한국어에 없음, 드묾, 고어, 전문어) 단어의 출신으로 고릅니다.
- 음독 한자어(한자를 모두 음으로 읽음) → **J**
- 훈독 고유어(てがみ, たべる처럼 일본 고유의 읽기) → **N**
- 음훈이 섞였거나(ほんや), 단어 통째로 붙은 읽기(きょう, おとな)이거나, 한자+가타카나(消しゴム) → **M**
- 한자가 없는 단어 → 가타카나 외래어 **L**, 그 밖의 가나 단어 **K** (이미 채워져 있음)

| 값 | 이름 | 한 줄 정의 | 앱 동작 |
| --- | --- | --- | --- |
| `S` | 동형동의 한자어 | 같은 한자 단어를 한국어에서 알아보고, 핵심 뜻이 같다 | 뜻 카드 생략, **읽기만** 묻는다 |
| `F` | 거짓 친구 | 같은 한자 단어가 한국어에 있으나 뜻·쓰임이 달라 오해를 부른다 | 빨간 경고 + `ff` 문구, 뜻 카드 먼저 |
| `J` | 일본 한자어 | 음독 한자어인데 한국어에서 알아볼 단어가 없다 | 뜻 카드 + 읽기 카드 |
| `N` | 고유어(和語) | 훈독으로 읽는 일본 고유어 | 뜻 카드 + 읽기 카드 |
| `M` | 혼종·기타 | 음훈 혼합, 숙자훈·아테지, 한자+가타카나 | 뜻 카드 + 읽기 카드 |
| `L` | 외래어 | 가타카나 외래어(자동) | 뜻 카드 |
| `K` | 가나 표기어 | 한자 없이 가나로 쓴 단어(자동) | 뜻 카드 |

### 판정 규칙 (어려운 경우)

1. **"알아보는가"가 기준입니다.** 일상 회화에 쓰지 않아도 간판·뉴스·서류에서 흔히 보아 뜻을 바로 아는 한국어 단어면 S입니다(大人 → '대인 요금'의 대인, 今日 → '금일 휴업'의 금일). 사전에만 있거나 고어·전문어여서 보통 사람이 모르는 단어(天気 → 천기, 去年 → 거년)는 "없음"으로 보고 J입니다.
2. **읽기 방식은 S/F 판정과 무관합니다.** 薬(くすり)은 훈독이지만 한국어 '약'과 같으므로 S, 大家(おおや)는 훈독이지만 한국어 '대가(大家, 거장)'로 오해하므로 F입니다. 읽기 방식은 `rt`에 따로 적습니다.
3. **한 글자 단어**는 한국어에서 그 한 글자가 **단독 단어로** 쓰일 때만 S/F입니다(자세히는 2.1의 R2). 山 → 산(단독으로 씀) S, 庭(にわ) → 정(단독으로 안 씀) N, 水(みず) → 수 N.
4. **뜻이 일부만 겹칠 때**: 이 단어장의 첫 번째 한국어 뜻(`ko` 맨 앞)과 한국어 단어의 핵심 뜻이 같으면 S. 일본어의 주된 뜻이 한국어와 다르고 겹치는 뜻은 드문 뜻이면 F. 先生(선생, 의사·변호사에게도 씀)은 핵심이 같으니 S, 生徒(せいと, 중고생)는 한국어 '생도'(사관생도)로 오해하므로 F.
5. **같은 한자, 다른 일상 쓰임**도 F입니다: 愛人(애인 ≠ 불륜 상대), 丈夫(장부 ≠ 튼튼함), 大丈夫(대장부 ≠ 괜찮음), 工夫(공부 ≠ 궁리), 迷惑(미혹 ≠ 폐), 大家(대가 ≠ 집주인). 반면 新聞(신문)과 汽車(기차)는 한국어와 같으므로 S입니다(汽車가 '자동차'인 것은 중국어 이야기). 手紙(てがみ)는 한국어에 '수지'라는 단어가 없으니 F가 아니라 N, 勉強(べんきょう)은 한국어 '면강'이 고어라 F가 아니라 J입니다.
6. **소리만 같고 한자가 다른 한국어 단어**는 F가 아닙니다. 意地(いじ, 고집)의 한국 한자음 '의지'는 한국어 의지(意志)와 한자가 다릅니다 → J. 丁度(ちょうど)의 '정도'도 한국어 정도(程度)와 다른 한자 → J.
7. **오쿠리가나가 붙은 동사·형용사**: 한자 부분으로 판정합니다. 食べる·青い처럼 훈독 고유어는 N. 음독 한 글자 + する/じる는 2.1의 R1을 따릅니다(感じる는 '감하다'가 다른 말이라 J, 応じる는 '응하다'라 S). 便利(な)(べんり) → 편리(하다) S. 心配(する) → '심배'는 한국어에 없으므로 J.
8. **접사(～が付く 표제어)**: `expr`의 ～는 무시하고 남은 부분으로 판정합니다. ～中(ちゅう) → '~중' S, ～式 → '~식' S, 再～ → '재~' S, ～屋(や) → 훈독 N, ～さん·お～ → 가나라 K.
9. **고유명사·숫자**: 一(いち) → '일' S, 日本(にほん) → '일본' S(읽기가 にほん이라도 한자 단어는 같음).
10. **가타카나 단어**: 외래어는 모두 L(和製英語 サラリーマン 포함). 가타카나로 쓴 의성어·의태어(ドキドキ)나 동식물명(トンボ)처럼 외래어가 아닌 것만 K로 바꿉니다.
11. **그래도 애매하면**: S 대신 J(또는 N/M)를 고르고 시트 맨 오른쪽 빈 열에 메모를 남기세요. 메모 열은 무시되니 자유롭게 써도 됩니다.

### 2.1 일관성 규칙 (2026-11 정리 — 청크 사이 판정이 갈렸던 유형)

모든 규칙의 바탕은 하나입니다: **"한국 성인이 이 단어를 한자로 보고, 배우지 않고도 맞는 뜻을 확실히 아는가?"** 그래야 뜻 대신 읽기만 물어도 안전합니다. S를 잘못 주면 뜻이 필요한 사람에게서 뜻 카드를 빼앗고, F를 잘못 주면 거짓 경고가 뜨며, J·N·M끼리 헷갈리는 것은 어느 쪽이든 뜻 카드가 남아 해가 없습니다. 그래서 **S는 보수적으로, F는 실제 함정에만** 줍니다. 아래에서 ✔는 `validate-tags.mjs`가 기계적으로 검사합니다(표·목록은 `scripts/enrich/tags-schema.mjs`).

| R6 보충 | 다리 단어가 **같은 소리의 더 흔한 다른 한자어**로 먼저 읽히는 말 | 읽기 카드는 한자 없이 한글 다리 단어만 보여 주므로, 그 소리를 들은 한국인이 **다른 한자의 더 흔한 말**을 먼저 떠올리면 S가 아니라 J입니다(뜻은 같아도). 소리만 같은 다른 말이 F를 막는다는 6번 규칙과 짝입니다: 동음어는 F의 근거도, S의 근거도 되지 못합니다. 동음어가 있어도 이 단어의 쓰임이 흔하고 문맥이 분명하면 S로 둡니다 | J: 点々 점점(→漸漸 차츰), 享受 향수(→香水·鄕愁), 相違 상위(→上位), 工員 공원(→公園), 修学 수학(→數學), 字体 자체(→自體), 大体 대체(→代替, 혼자 쓰면 '도대체') · S로 둔 경계: 自衛 자위(자위권·자위대), 不意 불의(불의의 사고), 出場 출장(선발 출장) |
| R7 | 훈독 복합어인데 한자가 한국어 한자어를 이루는 말 | 오쿠리가나·の를 빼고 남은 한자가 **같은 뜻의 현재 한국어 한자어**이면 S(`sk` = 그 단어, `rt`는 kun/mix 그대로). 한국어 단어의 뜻이 달라 오해하면 F. 겹치지 않으면 N/M | S: 取り消す 취소, 組み立てる 조립, 追い越す 추월, 日の出 일출, 家出 가출, 名札 명찰, 立場 입장, 手当 수당, 売り場 매장, 小包 소포, 受け取る 수취, 支払う 지불 · F: 引き出し 인출(서랍) · N: 植木(식목 ≠ 정원수), 引き出す, 結び付ける |
| R8 | 접사(～X, X～) | ～를 빼고 남은 한자가 **한국어에서도 같은 뜻의 접사·단위**로 쓰이면 S(`sk`는 접사 음 그대로: ～料 료, ～女 녀), 한국어 접사의 뜻이 다르면 F, 그런 접사가 없으면 음독 J·훈독 N | S: ～枚 매, ～台 대, ～島 도, ～省 성, 翌～ 익, 今～ 금, 初～ 초, 超 · F: ～年生(학년), ～着(벌), ～度(번), ～中(じゅう, '~내내'; ～中(ちゅう) '~중'은 S) · J: ～足(켤레), ～頭(마리), ～階(층), 御～ |
| R9 ✔ | `ff` 문구 | 한 형식으로 씁니다(4절). 따옴표 안 한국어 단어에 `sk`가 들어 있어야 하고 조사가 맞아야 합니다 | |
| R10 ✔ | 같은 표제어 | 같은 표기·같은 읽기·같은 접사 위치면 청크·급수가 달라도 `k`·`sk`·`ff`가 같아야 합니다(예외는 `SAME_WORD_EXCEPTIONS`에 이유와 함께). 접사 위치가 다르면 다른 말입니다(席 J ↔ ～席 S, 女～ 여 ↔ ～女 녀) | |

**F는 실제 함정에만.** 한국인이 그 한자어를 보고 떠올리는 뜻이 일본어의 주된 뜻과 **분명히 다를 때만** F입니다. 한국어 단어의 다른 뜻이 일본어와 같거나(人事 인사 관리, 境遇 형편, 年輪 나이테, 相対 상대적, 交替 선수 교체) 떠올린 뜻이 가까우면(不服 불복, 始発 시발역) F가 아니라 J입니다. 한국어 단어가 거의 쓰이지 않으면(得意 득의) 함정이 될 것도 없으니 J, 경고 문구가 '주로 ~'로 쓸 만큼 한쪽 뜻이 앞서지 않으면(風俗 풍속·풍습 / 유흥업소) F 대신 J로 둡니다(뜻 카드가 남아 해가 없음).

## 3. `sk` — 한국 한자음

- **S, F, J는 필수**, N·M은 선택(대개 비워 둡니다), L·K는 **반드시 비웁니다.**
- 표제어에서 ～와 가나를 뺀 **한자 한 글자당 한글 한 음절**입니다. 産業 → `산업`, 食べ物 → (N이면 비움), 人々 → `인인`(々는 앞 글자 반복).
- **한글 음절만** 씁니다. 공백, 한자, 가나, 영문, 괄호 금지.
- 한국어에서 그 단어를 읽고 쓰는 대로 씁니다. 한국어가 사이시옷을 붙여 쓰면 그대로(数字 → `숫자`, 回数 → `횟수`). 한국어가 다른 한자로 쓰는 단어는 일본 글자를 읽은 소리를 씁니다(膨張 → `팽장`, 2.1의 R5). **두음법칙 적용**(料理 → `요리`, 旅行 → `여행`, 労働 → `노동`, 女子 → `여자`), 比率 → `비율`. 단, 뒤에 붙는 접미사(～料)는 단어 첫머리가 아니므로 `료`.
- 한국어에 없는 J 단어도 **글자별 한국 한자음**을 씁니다(挨拶 → `애찰`, 弁当 → `변당`). 일본 신자체는 대응하는 한국 한자의 음으로 씁니다(図 → 도, 駅 → 역, 売 → 매).
- 후보(`sk_candidates`)가 틀렸으면 고쳐 쓰면 됩니다. 글자마다 독음이 여럿이면(楽 락/악/요, 行 행/항) 이 단어에서 한국어로 읽는 음을 고르세요(音楽 → `음악`, 銀行 → `은행`).

## 4. `ff` — 거짓 친구 설명

- **F에만, 반드시** 씁니다. 다른 유형에는 쓰지 않습니다.
- 한국어 한 줄, **60자 이내**, 일본어 문자(가나·한자) 금지. **형식은 하나**: `한국어 '<한국어 단어>'(<그 뜻>)와/과 달리 [주로] '<일본어 뜻>'(이)라는 뜻`. 일본어에도 한국어 뜻이 일부 있으면 `주로`를 넣습니다. 예: `한국어 '공부'(학습)와 달리 '궁리·고안'이라는 뜻`, `한국어 '금'(황금)과 달리 주로 '돈'이라는 뜻`.
- 사용자가 학습 화면에서 빨간 칩 아래로 봅니다. 사전식 설명 말고 차이만 짚으세요.

## 5. `rt` — 읽기 유형 (한자가 있는 단어에 필수, 가나 단어는 비움)

| 값 | 뜻 | 예 |
| --- | --- | --- |
| `on` | 모든 한자를 음독 | 産業 さんぎょう, 一 いち, 感じる かんじる |
| `kun` | 모든 한자를 훈독 | 手紙 てがみ, 食べる たべる, 山 やま |
| `mix` | 음독과 훈독이 섞임 | 本屋 ほん(음)+や(훈), 場所 ば(훈)+しょ(음), 仕事 し+ごと |
| `irr` | 글자별로 나눌 수 없는, 단어 통째의 읽기(숙자훈) | 今日 きょう, 大人 おとな, 一昨日 おととい |

후보는 KANJIDIC 음훈 목록으로 기계가 맞춘 값이라 대체로 맞지만, 숙자훈을 kun으로 잘못 맞추는 경우가 있습니다. 素敵(すてき)처럼 아테지라도 글자별 음독으로 나뉘면 `on`입니다.

## 7. 결과 파일 형식과 이름

두 가지 방법 중 하나로 냅니다.

**방법 A (권장) — TSV 그대로 돌려주기.** 시트에서 `k`, `sk`, `ff`, `rt` 열만 채우고, **파일 이름을 바꾸지 말고** 탭 구분(TSV)으로 내려받아 보냅니다(`n5-2.tsv`). 엔지니어가 다음 명령으로 변환·검사합니다.

```
node scripts/enrich/tags-import.mjs n5-2.tsv        # → data/tags/n5-2.json 생성 후 자동 검사
```

**방법 B — JSON 직접 작성.** 경로는 `data/tags/n<급수>-<번호>.json`(예: `data/tags/n5-2.json`). 청크의 **모든 단어 ID**를 키로 넣고, 빈 칸은 키를 생략합니다.

```json
{
"205":{"k":"K"},
"566":{"k":"S","sk":"일","rt":"on"},
"140":{"k":"M","rt":"mix"},
"1001":{"k":"F","sk":"공부","ff":"한국어 '공부'(학습)와 달리 '궁리·고안'이라는 뜻","rt":"on"}
}
```

허용 필드는 `k`, `sk`, `ff`, `rt` 넷뿐입니다.

## 8. 검사 (제출 전에 꼭)

```
node scripts/enrich/validate-tags.mjs data/tags/n5-2.json    # 한 파일
node scripts/enrich/validate-tags.mjs                         # 전체 + 급수별 집계
```

`ERROR`는 모두 고쳐야 제출할 수 있습니다(빠진 ID, 허용되지 않은 값, S/F/J인데 sk 없음, sk에 한글 외 문자, sk 음절 수 ≠ 한자 수, F인데 ff 없음, ff에 일본어 문자 등). 2.1의 ✔ 규칙과 같은 표제어 불일치도 `ERROR`입니다. `warn`은 확인만 하면 됩니다(후보에 없는 sk, 자동 후보와 다른 rt). 확인한 warn은 `data/tags/reviewed.json`에 `"w49v": "이유"`(단어 ID)로 적으면 다시 나오지 않습니다.

`data/tags/n5-1.json`은 이 안내대로 라벨링한 60단어 시범 청크입니다. 처음 시작할 때 함께 보세요.
