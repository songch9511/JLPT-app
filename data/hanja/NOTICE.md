# data/hanja — sources and licences

`kanji.tsv` is generated by `scripts/enrich/kanji-table.py` from two sources:

1. **Unihan database, Unicode 17.0.0** — field `kHangul` (column `ko_unihan`).
   File `Unihan_Readings.txt` (dated 2025-07-24), taken verbatim from the npm package
   `@vearvip/hanzi-readings@1.0.7` because unicode.org is not reachable from the build sandbox
   (sha256 of the file is pinned in `scripts/enrich/fetch-sources.sh`).
   Copyright © 1991-2025 Unicode, Inc. Licensed under the Unicode License v3, reproduced below.
   https://www.unicode.org/license.txt · https://www.unicode.org/reports/tr38/
2. **KANJIDIC2** (Electronic Dictionary Research and Development Group) — `korean_h`, `ja_on`, `ja_kun`
   (columns `ko_kanjidic`, `on`, `kun`), via the `jamdict-data` 1.5 package (KANJIDIC2 file dated April 2008).
   Used under the EDRDG licence (Creative Commons Attribution-ShareAlike):
   https://www.edrdg.org/edrdg/licence.html · https://www.edrdg.org/wiki/index.php/KANJIDIC_Project
   Because of these columns this file, and data derived from it (Korean-reading candidates), is
   distributed under CC BY-SA 4.0 with attribution to the EDRDG.
