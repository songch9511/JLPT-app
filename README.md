# 카사네 (重ね) — JLPT 단어장

간격 반복으로 겹겹이 쌓는 JLPT 단어 학습 PWA. 설치 없이 브라우저에서 열고, 홈 화면에 추가하면 앱처럼 오프라인으로 쓸 수 있습니다.

## 학습 방식 — 간격 반복

Anki가 쓰는 오픈소스 스케줄러 [FSRS](https://github.com/open-spaced-repetition/ts-fsrs)로 단어마다 "잊을 때쯤"을 계산해 그때 다시 보여 줍니다.

- 카드마다 **모르겠어요 / 알아요 / 쉬워요** 중 하나를 고릅니다. 버튼 아래에 그 단어가 다시 나올 시점이 표시됩니다.
- 새 단어는 같은 날 몇 분 간격으로 다시 확인한 뒤, 며칠 → 몇 주 → 몇 달로 간격이 벌어집니다.
- 복습에서 잊은 단어는 10분 뒤 다시 나오고 간격이 짧아집니다.
- 하루 분량은 "그날 돌아온 복습 + 새 단어 N개(기본 20)"입니다. 다 넘기면 끝이고, 중간에 나가도 그대로 이어집니다.
- 목표 유지율은 90%, 복습 간격이 21일 이상인 단어를 "장기 기억"으로 셉니다.

## 기능

- 게임 요소: 카드마다 XP(답과 무관하게 10), 레벨, 연속 학습, 일일 퀘스트 3개, 50단어마다 도장이 찍히는 급수 여정, 마스코트 다루마(오늘 분량을 넘길수록 색이 액체처럼 차오르고, 끝내면 가득 참)
- 목표 대시보드: 오늘 할 카드, 시험일 D-day, 시험 전에 필요한 하루 새 단어 수, 연속 학습, 장기 기억 단어 수, 기억 유지율, 7일 복습 예보, 학습 기록
- 학습 세션: 방금 선택 되돌리기, 발음 듣기, 북마크, 키보드(← 모름 · → 앎 · ↑ 쉬움 · Space 뒤집기)
- 급수별 화면: 기억 상태별 단어 수와 단어 목록
- 단어장: 전체 검색, 북마크, 자주 잊는 약한 단어
- AI (Anthropic API 키 필요): 단어별 예문 · 한자 풀이 · 암기 팁, 약한 단어로 만든 짧은 이야기
- 라이트/다크 테마, 백업 내보내기/가져오기

학습 기록과 API 키는 브라우저(localStorage)에만 저장됩니다.

## 개발

```bash
npm install
npm run dev      # 개발 서버
npm run build    # 타입 검사 + 프로덕션 빌드 (dist/)
npm run data     # data/raw + data/ko → public/data 재생성
```

## 배포

`main`에 푸시되면 `.github/workflows/deploy.yml`이 빌드해서 GitHub Pages에 올립니다.
저장소 Settings → Pages → Source가 "GitHub Actions"로 설정되어 있어야 합니다.

## 단어 데이터

- 단어 목록: [open-anki-jlpt-decks](https://github.com/jamsinclair/open-anki-jlpt-decks) (MIT, tanos.co.uk 기반) — `data/raw/`
- 한국어 뜻: `data/ko/n{급수}-*.json` (`{ "<idx>": "뜻" }`). 현재 N5 · N4 제공, N3~N1은 영어 뜻으로 표시됩니다.
- 한국어 뜻을 추가하려면 `node scripts/make-chunks.mjs <급수>`로 번역용 TSV를 만들고, 결과를 `data/ko/`에 넣은 뒤
  `npm run data`를 실행하고 `src/data.ts`의 `KO_READY`를 갱신합니다.
