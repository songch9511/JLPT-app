# JLPT 루마 — 제품화 작업 브리프

이 문서는 제품화 작업의 기준 문서입니다. 각 작업 담당자는 먼저 이 문서를 읽고, 자기 산출물을 `docs/plan/`의 지정된 파일에 씁니다.

## 제품 현황 (2026-11 기준)

- **제품**: 한국인 학습자를 위한 JLPT 단어 학습 앱. 코드 안의 현재 이름은 "카사네(重ね)"이고, 제품명은 "JLPT 루마"로 가는 방향입니다(마스코트 다루마에서 따옴 — 개명 여부는 미확정).
- **배포**: https://songch9511.github.io/JLPT-app/ (GitHub Pages, PWA). 저장소는 공개.
- **스택**: React 19 + Vite + TypeScript, 라우팅은 해시 기반, 상태는 `localStorage` 하나(`kasane.state.v2`). 백엔드·계정·분석 도구 없음.
- **학습 엔진**: FSRS 간격 반복(`ts-fsrs`). 답변은 모르겠어요 / 알아요 / 쉬워요. 하루 분량 = 돌아온 복습 + 새 단어 N개. 코드: `src/srs.ts`.
- **게임 요소**: XP(카드당 10, 답과 무관), 레벨, 연속 학습, 일일 퀘스트 3개, 50단어마다 도장 찍히는 급수 여정, 마스코트 다루마(시작 전엔 자고, 진행할수록 색이 차오름).
- **데이터**: N5~N1 8,130단어. 단어 목록은 open-anki-jlpt-decks(MIT, tanos.co.uk 기반), 한국어 뜻은 모델 번역(전수 검수 안 됨). 예문·품사·음성 파일은 없음(발음은 기기 TTS).
- **AI**: 단어별 예문·한자 풀이·암기 팁, 약한 단어 이야기. 지금은 사용자가 자기 Anthropic API 키를 설정에 넣고 브라우저에서 직접 호출(`src/ai-client.ts`) — 스토어 제품에는 맞지 않는 구조.
- **디자인**: 일본 전통색 팔레트(쪽빛 강조), Lucide 아이콘, 버튼 그룹당 프라이머리 하나 규칙. `src/styles.css` 상단 주석 참고.
- **테스트**: 자동화 테스트 없음. 지금까지는 헤드리스 브라우저로 수동 확인만 함.

## 산출물 작성 규칙

- 한국어로, 결론과 추천을 맨 앞에 씁니다. 대안을 나열만 하지 말고 하나를 추천하고 이유를 답니다.
- 외부 사실(스토어 정책, 수수료, 가격, 경쟁 앱 기능)은 직접 찾아 확인하고 출처 링크를 답니다. 확인하지 못한 것은 "미확인"이라고 표시합니다. 정책은 자주 바뀌므로 확인한 날짜를 적습니다.
- 맨 끝에 **"결정이 필요한 것"** 절을 두고, 제품 주인이 정해야 하는 항목을 추천안과 함께 번호로 적습니다.
- 다른 작업과 겹치는 내용은 해당 문서를 가리키기만 합니다.
- 문서는 400줄 이내로 씁니다.
