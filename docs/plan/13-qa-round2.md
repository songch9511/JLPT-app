# 13. QA 2차 — 출시 후보 점검

작성 2026-11-14 · 대상: 브랜치 `claude/great-thompson-6ertt1`(main과 같음) + 이 문서의 수정 · 버전 1.0.0

## 결론

1. **출시를 막는 버그(blocker)는 없었습니다.** 주요(major) 3개와 사소한(minor) 7개를 고쳤고, 고친 것마다 수정 전에는 실패하고 수정 후 통과하는 테스트가 있습니다(`tests/unit/qa-round2.test.ts`, `tests/e2e/qa-round2.spec.ts`).
2. 주요 3개
   - **Q1** 마우스·키보드를 함께 쓰면(데스크톱 웹, 키보드 붙인 iPad) 다음 카드가 보지도 않고 "모르겠어요"로 채점됨.
   - **Q2** 가져오기 검사를 통과한 백업 파일 하나로 앱이 매번 오류 화면으로 열림.
   - **Q3** 시험일 칸에 먼 연도(오타)를 넣으면 홈이 수십 초 멈추고, 9999년이면 메모리가 바닥남.
3. **화면마다 다른 함수로 세는 숫자는 모두 일치했습니다**(4절 표). 이 비교를 단위 테스트로 남겼습니다(`tests/unit/counts-agree.test.ts`).
4. 접근성: 수정 후 axe-core 위반 **0건**(11개 화면 × 라이트·다크). 성능: 가장 큰 상태(11,601장, 1년 기록)·CPU 4배 감속에서 다음 카드까지 중앙값 0.32초, 300장 학습에 힙 증가 약 4MB.
5. 남은 것은 모두 minor·cosmetic이고, 실제 iPhone·실제 서비스 워커 갱신·App Store 빌드는 여기서 확인할 수 없습니다. **6절의 20분 기기 점검**을 제출 전에 한 번 해 주세요.

## 6. 여기서 확인할 수 없는 것 — 기기 점검(약 20분)

실제 iPhone(iOS 16.4 이상, 가능하면 작은 화면 하나)과 TestFlight 빌드로 확인합니다. 순서대로 하면 20분 안팎입니다.

- [ ] **설치·첫 실행(2분)**: TestFlight에서 설치 → 비행기 모드 켜고 실행 → 시작 화면(루마) 뒤 홈에서 루마가 급수를 묻는지(오프라인 첫 실행). 비행기 모드 끄기. N4 → 첫 학습 시작, 설정에서 하루 10개.
- [ ] **학습(4분)**: 오늘의 학습 시작 → 카드 10장. 읽기 카드에서 오답 하나 고르기(빨강·초록 표시, 햅틱). 의미 카드에서 발음 버튼(일본어 음성). "되돌리기" 한 번 → 같은 카드가 다시 나오는지. 화면 위·아래가 노치·홈 막대에 가리지 않는지.
- [ ] **카드 넘기기(3분, 2026-11-14 추가)**: 카드 5장을 답한 뒤 카드를 오른쪽으로 밀어 앞 카드로 한 장씩 → 첫 카드에서 더 밀면 살짝 늘어났다 돌아오는지 → 왼쪽으로 밀어 지금 카드까지, 지금 카드에서 왼쪽은 늘어났다 돌아오는지. 손가락을 떼기 전 카드가 손을 따라가는지, 짧게 튕겨도 넘어가는지, 넘어갈 때만 가벼운 햅틱. 긴 카드(설명이 많은 단어)에서 위아래 스크롤이 넘기기로 바뀌지 않는지. 지난 카드에서 다른 평가를 눌러 ✓가 옮겨 가고 "남음" 수가 바뀌는지. **가장자리 충돌**: Safari(웹)에서 화면 왼쪽 끝부터 미는 뒤로 가기 몸짓이 앞 카드 넘기기와 겹치지 않는지(끝 20px은 시스템 몫), 앱에서는 왼쪽 끝 밀기가 아무 일도 하지 않거나 카드만 넘기는지. VoiceOver에서 "이전 카드"·"이후 카드" 버튼으로 같은 일이 되는지.
- [ ] **중간에 나가기(2분)**: 학습 중 앱 전환 → 30초 뒤 복귀 → 같은 카드. 앱을 완전히 종료(위로 쓸기) → 다시 열기 → 홈 숫자가 그대로(내구 사본).
- [ ] **알림·위젯(3분)**: 하루 분량을 끝내고 나오는 알림 제안에서 켜기 → 시스템 권한 허용 → 설정 › 알림 시각을 2분 뒤로 → 앱을 백그라운드로 → 알림이 오고 실제 복습 수를 말하는지(오늘 끝냈다면 안 와야 정상, 그때는 내일 날짜로 바꿔 확인). 홈 화면에 위젯 추가 → 오늘 복습·새 단어 수(작게), 만난 단어 수(중간)가 앱 홈과 같은지.
- [ ] **백업(3분)**: 설정 › 백업 내보내기 → 공유 시트 → "파일에 저장". 모든 기록 초기화 → 백업 가져오기 → 방금 파일 선택 → 숫자 복귀 → "가져오기 되돌리기"가 보이는지.
- [ ] **글자 크기·다크(2분)**: iOS 설정 › 손쉬운 사용 › 더 큰 텍스트를 최대 근처로 → 홈·학습·설정이 가로로 밀리지 않는지(학습 답 버튼은 Q18로 알려진 문제). 다크 모드 전환 → 상태 표시줄 색이 바탕과 맞는지(04 O9).
- [ ] **페이지(1분)**: 설정 › 개인정보 처리방침·도움말이 앱 안에서 열리고, 그 안의 외부 링크는 Safari 보기로 열리는지. 비행기 모드에서도 열리는지.
- [ ] **시간(2분)**: iOS 설정 › 일반 › 날짜 및 시간에서 자동 끄고 하루 뒤로 → 앱 복귀 → 홈이 새 날(복습이 생김)로 바뀌는지 → 자동 다시 켜기.
- [ ] **웹(1분, 같은 휴대폰 Safari)**: 배포 주소를 연 채로 새 버전을 배포한 뒤 다시 열기 → 학습 중 화면이 깨지지 않는지(서비스 워커 갱신, 04 O1).

그 밖에 여기서 못 본 것: 실제 서비스 워커 갱신 타이밍(Pages 캐시 헤더), WKWebView의 저장소 축출, 실제 TTS 음성 품질, VoiceOver 낭독 순서(axe는 구조만 봄), 저사양 기기의 실제 속도, App Store 심사 빌드 서명.
