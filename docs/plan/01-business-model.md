작성 2026-11-13. 외부 사실의 확인일은 따로 적지 않았다면 모두 2026-11-13이고, 출처는 맨 아래 [출처](#8-출처)에 번호로 모았습니다. 환율은 계획용 가정 **₩1,450/US$**로 계산했습니다(실제 환율은 확인하지 않음).

## 0. 결론

**추천: "무료 + 평생 이용권(일회성 구매) 하나"로 출시합니다. 광고와 구독은 넣지 않습니다.**

- **무료**: 전 급수(N5~N1) 8,130단어의 학습 루프를 그대로 둡니다. 간격 반복, 뜻·읽기·기기 TTS, XP·퀘스트·다루마, 기기 내 백업까지 무료입니다.
- **유료 "루마 플러스" 평생 이용권, 정가 ₩15,000(출시 할인 ₩9,900)**: 모든 단어의 예문·한자 풀이·암기 팁, 약한 단어 이야기(하루 1회), 클라우드 동기화(2단계), 고급 통계가 들어갑니다.
- **AI 원가 구조**: 단어 설명은 사용자마다 생성하지 않습니다. 8,130단어 전체를 **한 번만 미리 생성**(Sonnet 5.5 배치 기준 약 $37, ₩5.4만)해 모든 사용자에게 나눠 줍니다. 그러면 사용자 수가 늘어도 설명 비용은 0에 가깝고, 실시간 AI 원가는 이야기 기능만 남습니다. 이야기 원가는 사용자 1명당 월 $0.005~0.37입니다.
- **결제 구조**: iOS 앱(Capacitor 래핑, [06-app-store.md](06-app-store.md))에서 Apple 인앱 결제(비소모성 상품 1개)로 팝니다. 영수증 검증과 권한 관리는 **RevenueCat**에 맡기고(월 매출 $2,500까지 무료), 서버는 **Cloudflare Workers 하나**만 둡니다. Workers의 역할은 AI 프록시, 유료 콘텐츠 제공, 사용량 제한입니다. 웹 결제(국내 PG)는 출시 범위에서 뺍니다.
- **판매 1건당 순수령**: 소규모 사업자 프로그램(수수료 15%)에 가입하면 약 ₩11,600~12,950입니다. VAT 처리에 따라 달라지며 세무사 확인이 필요합니다.
- **1단계 구현량**: 1인 기준 약 3~4주입니다(iOS 래핑 제외).

핵심 숫자 세 가지:

1. **설명 사전 생성 1회 비용 $37~75**. 이후 사용자 수와 무관하게 0이고, 사용자별로 생성하면 1,000명 기준 월 $1,380입니다(Sonnet, 보통 사용자).
2. **이야기 원가는 플러스 사용자 1명당 월 최대 $0.37**(Sonnet, 하루 1회 상한). Haiku를 쓰면 $0.02입니다.
3. **판매 1건 순수령 약 ₩11,600**(₩15,000, 수수료 15%, VAT 납부 가정).

**B를 추천하는 이유**

1. **시장 관행**: 비교 기준인 회독JLPT가 "무료판 + 별도 유료판 ₩22,000" 구조입니다 [1]. 구독형 경쟁 앱(₩3,900~4,400/월 [2][3])도 시험까지 3~6개월 쓰면 총 ₩12,000~26,000이라, 평생 이용권 ₩15,000은 사용자 입장에서 계산이 쉽습니다.
2. **원가 구조**: 유일한 지속 원가인 AI를 사전 생성으로 고정비로 바꿀 수 있습니다(4절). 지속 원가가 작으면 일회성 과금이 성립합니다.
3. **운영 부담**: 1인 운영에서 구독(갱신 실패, 유예 기간, 가격 변경 동의, 해지 문의)은 부담이 큽니다. 비소모성 상품 하나는 "구매 / 복원" 두 흐름이면 됩니다.

### 4.2 호출 1회당 토큰 가정

`src/ai-client.ts`의 스키마와 프롬프트를 기준으로 추정했고, 실측은 아닙니다. 출시 전 `usage`를 로그로 남겨 보정해야 합니다.

- **단어 설명**: 입력 약 600(시스템 프롬프트, 단어 정보, 구조화 출력 스키마), 출력 약 800. 출력 800은 예문 2개(일본어·가나·한국어), 한자 풀이, 팁, 관련 단어 3개의 JSON 약 600에 사고 토큰 약 200을 더한 값입니다. Opus 5.5는 사고를 끌 수 없어 effort `low`라도 사고 토큰이 붙습니다.
- **약한 단어 이야기**(12단어): 입력 약 700, 출력 약 1,100. 출력은 제목과 4~6문장 × 3표기에 사고 토큰을 더한 값입니다.

| 단어 설명 | $0.00046 | $0.0092 | $0.0184 |

### 4.4 전역 캐시: 같은 단어는 같은 설명

단어 설명의 입력은 단어 정보뿐이라 사용자와 무관합니다. 그래서 **8,130단어를 한 번 생성하면 모든 사용자가 공유**할 수 있습니다. 지금은 기기마다 `localStorage`에 캐시해서(`src/ai.ts`) 같은 단어를 사용자 수만큼 다시 생성합니다.

| 방식 | 비용 |
| --- | --- |
| 전체 사전 생성, Sonnet 5.5 배치 | 8,130 × $0.0046 ≈ **$37 (1회)** |
| 전체 사전 생성, Opus 5.5 배치 | ≈ $75 (1회) |
| 전체 사전 생성, Haiku 5.5 배치 | ≈ $2 (1회) |
| 이후 추가 비용 | 사용자 수와 무관하게 $0. 전송·저장 비용만 남고 무료 등급 안에 들어갈 것으로 예상 |

- **효과**: Sonnet 기준 보통 사용자 1,000명이면 월 $1,380(설명분)이 1회 $37로 바뀝니다. 첫 달부터 **97% 이상 절감**되고, 둘째 달부터는 설명 원가가 0입니다. 사용자 27명이 한 달만 써도 사전 생성이 더 쌉니다.
- **부수 효과**:
  - 실시간 호출이 없어져 응답이 즉시 뜨고 오프라인에서도 볼 수 있습니다.
  - 생성물을 출시 전에 **검수**할 수 있습니다. 예문 오류는 학습 앱의 신뢰를 직접 깎습니다.
  - 그래서 이 기능은 "AI 기능"보다 **유료 콘텐츠**로 다루는 것이 맞습니다.
- **추천 모델**: 예문 품질이 상품 가치의 중심이고 생성은 1회뿐이라 **Sonnet 5.5 배치**를 씁니다. 급수별로 100단어씩 Haiku와 Sonnet을 비교해, 차이가 없으면 Haiku로 내립니다.

### 4.5 남는 실시간 원가: 이야기

이야기는 사용자의 약한 단어 조합마다 달라서 캐시할 수 없습니다.

| 플러스 사용자 월 이야기 수 | Haiku 5.5 | Sonnet 5.5 |
| --- | --- | --- |
| 2회 | $0.001 | $0.025 |
| 8회 | $0.005 | $0.10 |
| 30회(하루 1회 상한까지 사용) | $0.019 | $0.37 |

평생 이용권 1건 순수령 ₩11,600은 약 $8입니다. Sonnet으로 매일 쓰는 사용자는 약 22개월이면 매출을 다 씁니다. 그래서:

1. **하루 1회 상한**을 서버에서 강제합니다.
2. **기본 모델은 Haiku 5.5**로 둡니다. 품질 비교에서 부족하면 Sonnet으로 올리되, 상한을 주 3회로 낮춥니다.
3. 무료 사용자에게는 체험 1회만 줍니다. 무료 1,000명이 모두 체험해도 Haiku 기준 $0.6입니다.

## 5. 결제 연동 설계

### 5.1 Apple 규정 (2026-11-13 확인)

- **디지털 상품은 인앱 결제(IAP) 필수**: 앱 안에서 여는 기능·콘텐츠는 가이드라인 3.1.1에 따라 IAP로 팔아야 합니다. 앱 밖에서 산 권한을 앱에서 쓰게 하는 것(3.1.3(b) 멀티플랫폼)은 앱 안에서도 IAP로 살 수 있을 때 허용되는 것이 일반적인 해석입니다 [10]. 정확한 최신 조문은 Apple 페이지를 직접 열어 확인하지 못했으니 **미확인**입니다.
- **수수료**:
  - 표준 30%.
  - 소규모 사업자 프로그램(전년도 수익 100만 달러 이하) 15%. 미국·한국 등 대부분 국가에서 그대로이고, 2026년 변경은 중국(12%)과 EU(10월 1일부터 새 체계)에 한정됩니다 [7].
  - 가입해야만 적용되므로 **App Store Connect에서 신청**해야 합니다.
- **한국 제3자 결제**:
  - StoreKit External Purchase Entitlement로 KCP·이니시스·토스·NICE 결제를 쓸 수 있습니다.
  - 대신 **수수료가 26%**이고(소규모 사업자 감면은 확인되지 않음), 한국 전용 별도 바이너리가 필요하며, IAP와 함께 쓸 수 없습니다 [11].
  - 방미통위가 2026-10-28 애플에 과징금 208억 원과 시정명령(외부결제 링크 허용, 제3자 결제 수수료 개선)을 의결했습니다. 이행 기한은 3개월입니다 [12]. 2027년 초에 조건이 바뀔 수 있지만, 지금 15% IAP보다 유리하지 않습니다.
- **미국 스토어 외부 링크**: Epic 판결에 따라 현재 수수료 0%로 외부 구매 링크를 허용합니다. Apple이 15%를 제안한 상태이고 수수료 수준은 법원 심리 중입니다 [13]. 우리 고객은 한국이라 해당이 적습니다.
- **결론**: 한국 사용자 대상이고 소규모 사업자 프로그램 15%가 가장 싸며 구현도 가장 단순합니다. **iOS에서는 IAP만 씁니다.**

### 5.2 StoreKit 2 직접 구현 vs RevenueCat

| | StoreKit 2 직접 | RevenueCat |
| --- | --- | --- |
| 비용 | 0 | 월 추적 매출 $2,500까지 무료, 넘으면 전체의 1% [14] |
| 클라이언트 | Capacitor에서 Swift 플러그인을 직접 쓰거나 커뮤니티 플러그인 사용 | 공식 Capacitor SDK, 구매·복원 API, 페이월 도구 |
| 서버 검증 | App Store Server API와 JWS 서명 검증, 환불 알림(Server Notifications v2) 처리를 직접 구현 | 대행. 우리 서버는 REST API로 "이 사용자가 plus 권한이 있나?"만 물음 |
| Android·웹 확장 | 각각 따로 | 같은 권한 모델로 묶임 |
| 위험 | 구현량, 환불 처리 누락 | 외부 의존. 무료 등급의 웹훅 제한 여부 **미확인** [14] |

**추천: RevenueCat.**

- 우리 규모(월 매출 ₩300만 이하 ≈ $2,100)는 무료 등급 안입니다.
- 1인 개발에서 영수증 검증, 환불 시 권한 회수, 복원을 직접 짜는 2~3주를 아낄 수 있습니다.
- 비소모성 상품 하나라 나중에 StoreKit 2로 옮기기도 쉽습니다. 권한 판단을 우리 Worker의 `hasPlus(userId)` 한 곳에 모아 두면 됩니다.

### 5.3 웹 결제 경로 (PWA)

- GitHub Pages의 PWA는 App Store로 배포되지 않으므로 Apple 규정이 적용되지 않습니다. 웹에서는 국내 PG로 팔 수 있습니다.
- **Stripe는 한국 사업자 가입이 안 됩니다**(해외 법인 필요) [15]. 현실적인 선택지는 **토스페이먼츠 등 국내 PG(포트원으로 연동)**입니다. PG 가입 심사에는 사업자등록과 통신판매업 신고증이 필요합니다(수수료와 디지털 콘텐츠 심사 조건은 **미확인**).
- 웹 결제를 iOS 앱에서 인정하려면 계정(로그인)이 필요하고, iOS 앱 안에는 웹 결제 안내나 링크를 넣을 수 없습니다(한국 스토어).
- **추천**:
  - **출시 범위에서 제외**합니다. 웹은 무료로 유지해 iOS 앱의 체험·유입 통로로 씁니다. 지금의 "내 API 키" 방식은 웹 전용 고급 옵션으로만 남기거나 없앱니다(결정 항목 6).
  - 웹·Android 사용자가 의미 있게 생기면 2단계 동기화(로그인)를 만들 때 PG를 붙입니다.

### 5.4 최소 백엔드

API 키를 클라이언트에 둘 수 없으므로 서버가 최소 하나 필요합니다. 공개 저장소에 유료 콘텐츠를 올리면 누구나 받을 수 있다는 점도 함께 막아야 합니다.

```
iOS 앱 (React + Capacitor)
  ├─ RevenueCat SDK ── Apple IAP (상품: luma_plus_lifetime, 권한: plus)
  └─ HTTPS ─► Cloudflare Worker (api.도메인)
                ├─ GET  /explain/:wordId   → 권한 확인 → R2/KV의 사전 생성 JSON 반환 (무료: N5·일일 3개)
                ├─ POST /story             → 권한·일일 상한 확인 → Anthropic API(서버 키) → 결과 반환
                ├─ (2단계) PUT/GET /sync   → Sign in with Apple 토큰 확인 → D1에 상태 JSON 저장
                └─ 권한 확인: RevenueCat REST API 조회 결과를 KV에 10분 캐시
```

- **사용자 식별**: 1단계는 로그인 없이 RevenueCat 익명 ID를 씁니다. 구매는 Apple ID에 묶이므로 "구매 복원"으로 기기를 옮길 수 있습니다. 익명 ID를 위조해 남의 권한을 쓰는 위험은 이야기 일일 상한으로 피해를 묶고, App Attest 도입 여부와 위협 분석은 [07-security-operations.md](07-security-operations.md)에서 다룹니다.
- **Cloudflare를 고르는 이유**: 정적 콘텐츠와 프록시를 한곳에서 처리하고, 무료 등급으로 시작할 수 있습니다(무료 등급 한도 수치는 **미확인**, 계정 개설 시 확인).
- **유료 콘텐츠 위치**: 사전 생성 결과는 공개 저장소(`public/`)에 **넣지 않고** R2(비공개)에 둡니다.

   - 추천: **예.** 전환율이 1% 미만이면 급수 잠금을 실험한다.

   - 추천: **예.** 원어민 음성을 추가할 때 ₩19,000~22,000으로 재검토한다.
