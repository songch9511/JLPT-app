# 문구 목록 (홈·첫 실행 밖의 모든 화면)

작성 2026-11-14 · 기준: `docs/design-system.md` 3장 "문구"(소유자 규칙). 홈과 첫 실행은 이미 정리되어 이 표에 넣지 않았습니다(같은 규칙, 같은 용어).

이 문서는 두 가지 일을 합니다. (1) 이번에 바꾼 글자를 소유자가 한눈에 볼 수 있게 화면별로 **전 → 후**와 한 단어 이유를 적습니다. (2) 앞으로 새 글자를 쓸 때 맞출 **용어집**과 **라벨 규칙**을 둡니다(맨 아래).

이유 표시: **삭제**(화면이 이미 말함) · **줄임** · **용어**(용어집에 맞춤) · **부사**(부사·강조어 뺌) · **느낌표** · **추임새** · **형식**(숫자·단위·문장 부호) · **유지**(그대로 둠, 이유를 적음).

세어 보니 대상 파일의 한국어 글자 조각 **243개**(보이는 글자, 화면 낭독기 이름, 알림·위젯 글자, 학습 화면의 단계·유형 라벨 포함. 단어 데이터·`ff`·정책 페이지는 세지 않음)를 보았고, **78개를 바꿨습니다: 통째로 지운 것 7개, 줄이거나 고친 것 71개**(그중 여러 문장에서 설명 문장을 덜어 낸 것이 20여 개). 나머지 **165개는 그대로**입니다.

## 배치를 고친 곳

- 학습 · 오늘 끝: 설명 문장이 빠져 제목 바로 아래 결과 칸이 옴(간격은 화면의 `gap` 그대로, 따로 고칠 것 없었음). 기다림·밀린 복습 상태에서만 한 줄이 남음.
- 학습 · 앞면: 안내 알약(`.flash-hint`)을 지우고 그 스타일도 지움. 답 자리(`.flash-answer-slot`, 최소 72px)는 그대로라 정답을 열어도 카드가 흔들리지 않음.
- 기록: 복습 예보 카드는 제목과 막대만, 도장 아래 줄은 홈과 같은 "만난 단어 n / 전체" 꼴.
- 설정 › 학습 방식: "루마의 안내를 다시 켰어요."가 그 자리에 있던 글자 버튼과 같은 안쪽 여백(`.replay-done`)으로 놓여 왼쪽으로 튀어나가지 않음(전에는 카드 안쪽 여백 밖으로 8px 나가 있었음).
- 단어장·급수: 숫자에 천 단위 쉼표(홈과 같음). 검색 전 안내 문장이 빠져 검색칸 바로 아래 "급수별 기억 상태"가 옴.

## 일부러 남긴 설명

규칙 1은 "화면이 이미 말하는 것"만 지웁니다. 아래는 화면 어디에도 없고, 없으면 학습자가 손해를 볼 수 있어 짧게 남긴 것입니다.

- **되돌릴 수 없음·잃는 것**: 초기화 확인(설정과 오류 화면), 백업으로 바꾸기 확인("되돌릴 수 있어요").
- **저장 위치와 백업**: 설정 › 데이터의 "이 기기(브라우저)에만 저장돼요", 저장 실패 배너, 오류 화면의 "기록은 그대로 있어요".
- **가져오기 실패**: 무엇이 문제고(새 버전의 백업) 무엇을 할지(업데이트·새로고침).
- **효과가 라벨로 드러나지 않는 설정**: 아래 급수 함께, 하루 새 단어(복습이 늘어남), 한자어 빠른 통과(끄면 모두 뜻 카드), 복습 알림(있는 날만 하루 한 번), 진동(동작 줄이기와의 관계).
- **알림 권한을 묻기 전**: 언제·얼마나 알리는지. 거절 뒤에는 어디서 켜는지.
- **정의**: 약한 단어(두 번 이상 잊음), 북마크가 모이는 곳, 히트맵의 색(진할수록 많이 본 날), 도장 범례(만난 단어 50개마다).
- **시각**: 기다림 화면의 "40분 뒤".

## 라벨 규칙

- **버튼은 짧은 동사**, 같은 동작은 어디서나 같은 라벨: 시작하기 · 계속하기 · {n}장 더 · 새 단어 10개 더 · 다음 · 홈으로 · 다시 시도 · 다시 불러오기 · 알겠어요(알림·팁 닫기) · 취소 · 모두 지우기 · 모든 기록 초기화 · 백업 내보내기 · 백업 가져오기.
- 화면에 짧게 쓴 버튼은 **화면 낭독기 이름을 자세하게**: "50장 더" = "밀린 복습 50장 더 하기", "새 단어 10개 더" = "새 단어 10개 더 하기".
- **숫자와 단위**: 천 단위 쉼표(2,460), 숫자와 단위는 붙여 씀(127장, 21분, 40개), 남은 양은 "{n}장 남음", 시각은 "{n}분 뒤", 분수는 "만난 / 전체".
- **빈 상태 제목**은 무엇이 비었는지를 마침표 없이("북마크한 단어가 없어요"). 설명은 채우는 법이 화면에서 보이지 않을 때만.
- **배너·대화상자 문장**은 마침표로 끝나는 평서문. 낭독용 이름은 쉼표로 이음("나가기, 진행 상황은 저장돼요").
- 느낌표·말줄임(…)·추임새·부사(조금만, 딱, 정말, 아주, 가볍게, 바로, 잠깐, 아직, 지금까지)는 쓰지 않습니다. "더"·"다시"·"지금"은 그것이 동작 자체일 때만(50장 더, 다시 시도, 1장 지금 하기).
