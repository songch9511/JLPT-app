# JLPT 루마 도움말

> 게시용 초안(2026-11-14). 제안 주소: `https://songch9511.github.io/JLPT-app/support/`. Apple은 지원 URL이 "실제 연락처로 이어져야 한다"고 요구하므로 맨 아래 연락처를 채운 뒤 게시합니다. `[대괄호]`는 운영자가 채울 자리입니다. 이 상자는 게시하지 않습니다. 게시되는 페이지는 `npm run pages`가 이 파일에서 만듭니다(`public/support/index.html`, 앱의 설정 › 정보 › 도움말 · 문의도 같은 페이지).

JLPT 루마는 한국어로 일본어능력시험(JLPT) 단어를 익히는 앱입니다. 계정이 없고, 학습 기록은 내 기기에만 저장됩니다.

JLPT 루마는 일본국제교류기금(JF)·일본국제교육지원협회(JEES)와 관계없는 비공식 학습 앱입니다.

## 백업과 복원

학습 기록은 이 기기에만 있고 서버에 따로 보관되지 않습니다. 가끔 백업해 두세요.

**백업 내보내기**
1. 설정 › 데이터 › **백업 내보내기**를 누릅니다.
2. 공유 화면에서 **"파일에 저장"**(iCloud Drive 등), AirDrop, 메일 중 원하는 곳으로 보냅니다.
3. 저장하면 설정 화면에 "마지막 백업" 날짜가 바뀝니다. 공유를 취소하면 바뀌지 않습니다.

**백업 가져오기**
1. 설정 › 데이터 › **백업 가져오기**를 누르고 백업 파일(`jlpt-ruma-backup-날짜.json`)을 고릅니다.
2. 확인하면 지금 기록이 백업 파일의 기록으로 **바뀝니다**(합쳐지지 않습니다).
3. 잘못 가져왔다면 같은 화면의 **가져오기 되돌리기**로 바로 전 상태로 돌아갈 수 있습니다.

## 새 iPhone으로 옮기기

- **iCloud 백업이나 컴퓨터 백업으로 새 iPhone을 설정하면** 앱 기록도 함께 옮겨지는 것이 보통입니다. 다만 앱만 새로 설치한 경우에는 옮겨지지 않습니다.
- 가장 확실한 방법: 예전 iPhone에서 **백업 내보내기 → 파일에 저장(iCloud Drive)** → 새 iPhone에서 앱을 설치하고 **백업 가져오기**.
- 웹 버전(브라우저)에서 쓰던 기록도 같은 방법으로 옮길 수 있습니다. 웹 버전 설정 › 데이터 › 백업 내보내기로 받은 파일을 앱에서 가져오면 됩니다.
- 앱을 지우면 기기 안의 기록도 지워집니다. 지우기 전에 백업하세요.

## "시험날 기억할 단어"는 무엇인가요?

- 지금까지 복습한 기록으로 계산한 **추정치**입니다. 고른 급수의 단어 목록 가운데 시험날 아침에 기억하고 있을 단어가 몇 개쯤인지 보여 줍니다.
- **합격 확률이 아닙니다.** 단어는 시험의 일부일 뿐이고, 문법·독해·청해는 들어 있지 않습니다. 앱이 쓰는 단어 목록도 공식 목록이 아닙니다(JLPT는 공식 어휘 목록을 공개하지 않습니다).
- "지금 그만두면"은 오늘부터 더 공부하지 않을 때, "계획대로면"은 하루 분량을 계속 할 때의 추정입니다.
- 목표(70%·80%·90%)는 앱이 정한 기준이지 합격선이 아닙니다. 설정 › 학습 목표에서 바꿀 수 있습니다.
- 복습 답이 30개쯤 쌓이기 전에는 "아직 판단하기 일러요"라고 나옵니다.

## 한자어 빠른 통과

한국 한자어와 뜻이 같은 단어(産業 = 산업)는 뜻 대신 **읽기**를 4지선다로 묻습니다. 모든 단어를 뜻 카드로 배우고 싶으면 설정 › 학습 방식 › **한자어 빠른 통과**를 끄세요.

## 복습 알림 (iPhone 앱)

- 하루를 처음 끝냈을 때 알림을 받을지 묻습니다. 나중에 설정 › 알림 · 진동 · 발음에서 켜고 끌 수 있습니다.
- 복습할 단어가 있는 날에만, 정한 시각에 하루 한 번 옵니다. 그날 분량을 이미 끝냈으면 오지 않습니다.
- 알림이 오지 않으면 iPhone 설정 › 알림 › JLPT 루마에서 알림이 허용되어 있는지 확인해 주세요.
- 앱을 7일 넘게 열지 않으면 알림이 멈춥니다. 앱을 다시 열면 이어집니다.

## 발음이 들리지 않아요

- 발음은 iPhone에 들어 있는 일본어 음성으로 읽습니다. 설정 › 알림 · 진동 · 발음에서 음성을 고르고 들어 볼 수 있습니다.
- 일본어 음성이 없다면 iPhone 설정 › 손쉬운 사용 › 읽기 및 말하기 › 음성에서 일본어 음성을 내려받으세요. [앱 안내 문구와 같은 경로. iOS 버전별 메뉴 이름은 기기에서 확인 필요]

## 처음부터 다시 하기 (초기화)

설정 › 데이터 › **모든 기록 초기화**를 누르면 학습 기록과 설정, 예약된 알림, 위젯 내용이 모두 지워집니다. **되돌릴 수 없으니** 먼저 백업해 두세요. 목표 급수나 하루 새 단어 수만 바꾸고 싶다면 초기화하지 않고 설정 › 학습 목표에서 바꾸면 됩니다.
